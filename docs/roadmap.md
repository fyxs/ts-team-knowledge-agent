# TS Knowledge Agent 路线图

## V1

- React + TypeScript + Vite 前端骨架
- FastAPI 后端骨架
- AG-UI 协议边界（默认 SSE）
- CLI 初始化与成员空间配置
- 每小时源目录扫描
- MinerU 转换
- 知识沉淀到固定 Git 仓成员空间
- SQLite 元数据与 FTS5 搜索
- 每小时 Git 批次同步
- 删除检测、异常暂停和本地日志

## V2

- 本地 Web 搜索和流式知识问答
- AG-UI SSE 端到端实现
- 只读知识服务
- Claude Code/Hermes 显式接入
- 语义检索和评测
