# 知识检索

## 步骤

1. 先从问题中抽出 2 到 4 个关键词，不要直接使用整句。
2. 调用 knowledge_search，先用最具体的关键词。
3. 零结果时依次尝试：去掉限定词、换同义词、缩短关键词、改用英文术语。
4. 结果过多时叠加更具体的词，或用 member / prefix 缩小范围。
5. 片段不足以判断时，用 knowledge_read 读取命中文档的正文。

## 注意

- 中文检索对连续词组敏感，短词召回更全。
- search 返回的 matched_by 为 substring 时，说明是子串命中，需要读正文确认。
- 不要因为一次零结果就回答“没有”，至少换两次关键词。
