# 来源与引用

## 规则

1. 每一段结论后附来源路径，路径必须来自工具返回值。
2. 事实来自知识库；推断是你自己的判断，必须写“推断”并在必要时说明依据。
3. 知识库内容相互冲突时，列出双方来源，不要擅自选一个当结论。
4. 找不到依据时明确写“知识库中没有找到”，并列出检索过的关键词。
5. 不要引用未实际读取过的文档路径。

## 输出建议

```text
结论：
依据：
  - <path>：<原文要点>
推断：
不确定项：
```
